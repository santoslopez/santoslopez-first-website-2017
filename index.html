Wiki

Sistema que simula el funcionamiento de Wikipedia. Permite buscar, crear, editar y mostrar páginas. El proyecto está realizado con el Framework Django. En la práctica sería tedioso si todas las páginas de Wikipedia se muestran en HTML, por esto se utilizó un sistema más ligero y amigable llamado Markdown, aunque Wikipedia implementa un sistema llamado Wikitext.

Buscador

Sistema realizado en Html, CSS y Boostrap que permite realizar búsqueda por medio de un formulario hacia Google. El proyecto permite realizar búsquedas por medio de imágenes, texto y búsqueda avanzada, trata de verse lo más posible al motor de búsqueda de Google y su funcionamiento.
